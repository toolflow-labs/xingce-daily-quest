# Xingce Daily Quest

连续 90 天，把每天一张行测试卷做成一个完整、可玩的网页副本。

## Paper 001：河南公务员录用考试《行测》

当前版本已经从早期的“随机抽 8 题战斗 Demo”重构为完整试卷引擎：

- 收录原卷 **120 道题**，保持原题顺序；
- 按 6 个模块组织为章节地图；
- 文字题完整转录；图形题、几何图、曲线图与资料表格使用从原 PDF 提取的原始图像资产；
- 图形推理、几何图、折线图选项等视觉题自动展开题图；
- 资料分析按共同材料分组，材料在组内 4—5 题之间保持；
- 记录答案、标记题和章节进度；
- 使用 `localStorage` 自动保存本机进度；
- 战报统计完成度、标记数与 A/B/C/D 选择分布。

### 为什么暂时不显示正确率

用户提供的 PDF 只包含试题，没有答案和解析。因此项目不会凭模型判断伪造答案。

当前 `paper-data.js` 中所有题目的 `answer` 均为 `null`。以后获得可靠答案文件后，可以单独导入答案层，再增加正确率、错题复盘与即时反馈。

| 材料 | 题号 | 原卷页 |

| 某市农业及水产品生产 | 106—110 | 20—21 |

原卷在出口材料标题处仍写“回答 111～115 题”，但随后实际题号为 116—119。项目保留这一源卷异常，并按真实材料关系组织题目。

## 运行

项目不需要安装依赖。

```bash
python -m http.server 8000
```

浏览器访问：

```text
http://localhost:8000
```

直接打开 `index.html` 也可运行；图片和数据均保存在仓库中。

## 操作

- 点击 A/B/C/D 选择答案；
- 左侧题号可快速跳转；
- 星标用于标记需要回看的问题；
- 图形题自动展开题图；
- 含图题及资料分析可点击原图缩略图放大；
- 键盘 `A`—`D` 可直接选择；
- 左右方向键切换题目。

## 内容边界

- 本仓库不上传原始 PDF 文件；
- 为完整保留图形、表格及排版关系，使用了用户提供试卷中提取的原始图像资产；
- 题目文本来自该 PDF 的可提取文本层；
- 项目用于个人学习和交互设计实验；
- 第三方试题、品牌及资料版权归原权利人所有。
